PROJECT OVERVIEW

Connect devices. Share locally.

DroidShare WiFi is being developed as a local-network sharing experience for Android and Windows. The project is designed around device discovery and a secure pairing flow, without requiring users to type IP addresses or ports manually.

01

Local device discovery

Discover nearby devices over a shared Wi-Fi network using UDP discovery.

02

QR-assisted pairing

Use a short-lived QR code to start a pairing session with a Windows companion.

03

Secure identity checks

Certificate pinning, one-time nonce validation, user approval and Android Keystore key proof are part of the pairing design.

04

Cross-platform foundation

Android and Windows components share protocol specifications for consistent communication.

DEVELOPMENT STATUS

Building the foundation.

The current public repository documents discovery, diagnostic connectivity and secure device pairing. Full file transfer, transfer resume, DLNA streaming and remote folder access are still on the roadmap and are not presented here as released features.

Current implementation

  • Android and Windows project structure
  • UDP device discovery and TCP handshake diagnostics
  • QR-based pairing with certificate pinning
  • Windows approval and trusted-device identity storage

Planned work

  • Trusted-device management on Android
  • File transfer and resumable transfers
  • DLNA media streaming
  • Remote folder access and device interoperability testing
