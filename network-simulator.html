PROJECT OVERVIEW

Reproduce network issues. Test with control.

Network Simulator is a portable-first Windows tool that places a configurable TCP proxy between physical Android POS terminals and an upstream server. It helps developers investigate connectivity and response-handling behaviour under controlled network conditions.

01

TCP and TLS passthrough

Bidirectional TCP relay with TLS forwarded as opaque bytes; the proxy does not terminate or decrypt TLS.

02

Network fault controls

Apply directional latency, jitter, bandwidth limits and request/response forwarding pauses.

03

ISO8583 DE 3 rules

For plain TCP profiles, configure Processing Code rules to leave traffic unchanged, block matching requests or alter the complete response frame.

04

Profile-based dashboard

Manage multiple endpoints, listener ports, profile import/export, connection state and byte counters from a local HTML dashboard.

VERSION 1.0

Built for practical POS testing.

The portable Windows EXE can run without a separate Python or Flask installation. Download availability is managed through the project repository's Actions build artifacts; no direct public installer link is advertised on this page.

Included capabilities

  • Independent TCP endpoint profiles
  • Directional latency, jitter and bandwidth throttling
  • Request/response forwarding pause and active socket abort
  • Metadata-only event log and local dashboard
  • JSON profile import/export

Important limitations

  • TLS payload remains encrypted and opaque
  • DE 3 rules apply to plain TCP only
  • Not a packet-loss, SYN-blackhole or Wi-Fi outage emulator
  • Corporate firewall and network controls may require IT approval
